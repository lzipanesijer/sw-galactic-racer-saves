## Overview

A curated collection of save files for Star Wars Episode I: Racer covering all circuits unlocked, all racers purchased, and multiple completion states for both casual exploration and 100% runs.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **SW Galactic Racer Saves** delivers the features you need in a clean, intuitive package.
